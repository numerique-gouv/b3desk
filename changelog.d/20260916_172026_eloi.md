### Actions requises

- Le code de l'application est désormais embarqué dans l'image Docker, au lieu
  d'être monté depuis le dépôt. Les mises à jour doivent donc reconstruire
  l'image : `docker compose -f docker-compose.yml -f docker-compose.prod.yml up
  --build`. Un `git pull` suivi d'un simple redémarrage des conteneurs ne
  change plus ce qui s'exécute.
