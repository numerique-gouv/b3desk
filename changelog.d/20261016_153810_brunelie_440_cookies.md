### Sécurité

- Le cookie de session porte désormais l'attribut `SameSite=Lax` et, lorsque `PREFERRED_URL_SCHEME` vaut `https`, l'attribut `Secure`. ({pr}`451`, {issue}`440`, {user}`funelie`)
- Le cookie de session ne contient plus qu'un identifiant. ({pr}`451`, {issue}`440`, {user}`funelie`)
- Les sessions sont désormais stockées dans le serveur redis indiqué par `REDIS_URL`, déjà utilisé par le worker. Si `REDIS_URL` n'est pas renseigné pour le service web, elles sont stockées sur le système de fichiers local, qui n'est pas partagé entre plusieurs serveurs. Les sessions en cours sont perdues à la mise à jour : chaque personne devra se reconnecter une fois ({pr}`451`, {issue}`440`, {user}`funelie`)
